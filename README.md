# Shadow Protocol

A top-down stealth infiltration game for the [make.fun "Make the best stealth game" bounty](https://make.fun/bounty/best-stealth-game-20261121-1759).

## Play

```bash
# Serve locally
node serve.ts
# Open http://localhost:8080 in Chrome
```

## Controls

- **Move**: `W` `A` `S` `D` or Arrow Keys
- **Sneak** (slow, silent): Hold `Shift`
- **Interact / Open Exit**: `E` or `Space`
- **Pause**: `Esc`

## Gameplay

Navigate through 5 increasingly difficult sectors, avoiding guards with vision cones. Use cover (crates, walls) to hide. The exit only opens when all guards are calm. Sneaking preserves your stealth meter - running drains it. If detected, guards will investigate and eventually chase you.
